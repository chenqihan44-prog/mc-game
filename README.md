# 方野：余烬灯塔

Windows 单人离线体素生存与建造游戏的开发版本。原计划见 [docs/开发计划.md](docs/开发计划.md)，真实进度与未通过关卡见 [docs/实施进度.md](docs/实施进度.md)。目前是可以运行的样板，不是已完成 S0–S7 验收的产品。

新版主线加入五处遗址、分阶段灯塔、三名区域精英、深层守护者、三种实体机关和约 11 格高的熔心巨像。新建世界进入后按 J 查看日志；旧世界保留原有生成版本与路线。详见 [三塔归火更新](docs/三塔归火更新.md)。80% MC 末影龙难度是平衡目标，完成时长与实际难度尚需玩家试玩确认。

2026-10-12 探索更新：可恢复的世界删除、区域补给箱、可拖动缩放的分支任务导图、六种开局地貌和新植物。新地形仅用于新建世界，旧存档地貌保留。详见 [探索体验更新](docs/探索体验更新-2026-10-12.md)。

新增：出生物资按种子分散、稀疏斑块植被、旧探索版世界更新自然地表、世界与备份永久删除。详见 [自然地表与永久删除更新](docs/自然地表与永久删除更新-2026-10-12.md)。

2026-10-12 光照与拾取更新：矿洞天光遮挡、贴墙火把和平滑衰减光照；默认关闭的出生奖励箱、稀有野外箱、修正水底草皮与露天晶矿；物品分别落地显示，身体接触后自动拾取。详见 [光照与掉落更新](docs/光照与掉落更新-2026-10-12.md)。

跳跃放块修复：分开碰撞和光照更新，后台重算光照，避免角色在落地前等待光照而滞空。详见 [修复说明](docs/跳跃放块修复-2026-10-12.md)。

## 运行

当前跳跃放块修复版为 `builds/EmberLighthouse-jumpfix试玩包.zip`；完整解压后双击 `EmberLighthouse.exe`。也可运行 `builds/EmberLighthouse-jumpfix/EmberLighthouse.exe`。保留同目录 `.pck` 和 `data_EmberLighthouse_windows_x86_64`，不能只复制 EXE。发布包包含 .NET 运行时，无需安装编辑器或 SDK。

新版加入图形3×3工作台、206种物品图标、挖掘裂纹/碎屑/进度条、3D角色预览与第一人称持物动画。按最新试玩反馈，开发阶段优先补齐成品体验，完整Bug回归与S7测试留到内容完成后。具体操作见 [成品体验更新](docs/成品体验更新.md)。

2026-10-11 更新：人物改为参考图的黑发蓝眼冒险者，六类生物按确认的预览区分模型与步行动画；存档显示种子、模式、保存时间、位置与编号；修复配方搜索清空后回填、创造与休闲同时选中的问题，增加物品拖动预览及落格动画，强化夜色、晨昏过渡与夜间刷怪。详见 [试玩反馈修复](docs/试玩反馈修复-2026-10-11.md)。

后续更新：目标放在右上角，悬浮提示使用深底白字；白天 10 分钟、夜晚 5 分钟，地图旁显示天亮/入夜倒计时。新增木镐、木斧、木锹、木剑、可贴墙与地面放置照明的火把；镐、斧、锹、剑、弓及盾牌有耐久。怪物平滑追踪移动目标、绕障、近战前摇中缓慢逼近，哨兵会拉开距离和侧移。

在主菜单创建世界，种子每次自动随机生成；可点击“随机种子”更换，清空后进入世界也会自动生成。仍可手动输入整数复现相同地形，实际种子会保存在存档中并显示在世界管理。默认生存，另有休闲难度与创造模式。种子 42 用于固定回归场景。出生点保留安全落脚区，教程材料按种子分散。可选择一个出生奖励宝箱，默认关闭；普通野外箱较稀少，地形与资源随种子变化。

大地图只显示已探索区域的地表方块、树木和建筑；走过的区域随存档保存，未探索区域与其中的灯塔保持隐藏，拖动或缩放不会揭开地图。放置与拆除后自动刷新。按 M 打开或关闭，左键/中键拖动、滚轮围绕鼠标缩放；提供定位玩家、全图、当前位置标记和比例尺。放大采用像素清晰显示，横纵比例一致；查看地图时暂停生存计时。

新建世界使用生成器第 7 版，出生地森林与平地通过不规则圆形边界自然衔接周边，移除原 96×96 格强制森林方块。旧世界继续使用原生成器，已有地形与建筑位置保留。旧存档没有行走路线记录，地图探索从当前所在位置开始累计。

## 生存路线

1. 出生地有原木、碎石、莓果。左键获取，C 制作木板、木棍与木镐；木镐采石后升级石镐。地面碎石也可直接拾取用于制作石镐。
2. 制作工作台、火把、营火和木箱，右键放置，Q 使用；营火附近有普通敌人的 7 格安全区；主线精英与 Boss 不受限制。火把与提灯放置后照明，矿洞内建议提前准备足够火把。
3. 进入附近洞穴，采煤与粗铁；工作台制作熔炉，Q 冶炼。返回游戏后计时，Q 的容器界面取出产物。
4. 在出生点东南约 `(32,24)` 的废营地木箱找到作物与材料。制作种子，放置耕地，右键播种，成熟后 Q 收获。
5. 制作床设复活点，夜间使用可过夜。标准死亡保留多份可取回背包，M 查看位置。
6. 探索废矿场取得检修证明，制作铜线圈修复寻路塔；旱地和雪岭两处精英提供棱镜，修复校准塔后制作余烬装备。
7. 在深层晶穴击败守护者，制作符印修复镇封塔；随后完成地心遗址的电桥、反射器、供能室节点，挑战熔心巨像。J 日志提供方向与准备建议。

世界水平 4096 格、高 192 格，静态水支持游泳。没有动态流体与水桶搬运。暂停和失焦会停止世界模拟。

## 存档

正常运行放在 `%APPDATA%/Godot/app_userdata/方野：余烬灯塔/worlds`。世界数据、背包、设施、死亡背包、作物与进度以统一代际提交，保留最近三代有效存档；遇到损坏会尝试恢复完整代际并提示，无法恢复时保留原文件并报错。

每 60 秒自动保存，暂停菜单可手动保存与备份。主菜单可读取和备份已有世界。备份放在同级 `backups`；可在世界管理的「从备份恢复」恢复为新世界，原档和备份保留。保存失败会显示错误并阻止正常的保存退出流程。

## 构建与验证

```powershell
.\tools\bootstrap.ps1 -Templates
.\tools\build.ps1 -Test -Export -OutputName EmberLighthouse-content
```

锁定 Godot 4.6 stable .NET、.NET SDK 8.0.425 与配套导出模板。工具下载及 SDK 校验在 bootstrap 中；Godot 包使用官方发布 SHA-256，SDK 使用官方 SHA-512。Godot SDK 从编辑器附带的本地 NuGet 源读取。中文工程路径下使用临时目录中的 ASCII SDK 路径，避免引擎探测乱码。测试时应用目录重定向在工作区，正常发布包使用系统应用数据目录。

核心测试为独立 .NET 可执行程序，无测试框架下载依赖；涵盖坐标、确定性、网格、背包事务、计时产出、连续死亡、校验恢复、未来版本拒绝及五个真实进程中断点。运行报告位于 `test-results`。场景检查不能替代长期人工游玩或真人试玩。

素材来源见 `assets/LICENSES.md`；发布包包含 Godot 与第三方版权声明。

## 项目文件整理

`builds` 仅保留当前 `EmberLighthouse-content` 目录、对应试玩 ZIP 和 SHA256 清单。旧导出目录及压缩包已清理，历史测试记录与测试存档归档到 `test-results/archived-builds`，本次归档位于其 `2026-10-12` 子目录；历史报告中的旧包路径仅记录当时的验证对象，不能用于重新验证已删除的包。

格式 2/3 的真实旧版 DLL 与 GodotSharp 依赖保存在 `tests/fixtures/published-format2`、`tests/fixtures/published-format3`，供 `tools/test-save-compat.ps1 -OldFormat 2` 或 `-OldFormat 3` 使用；历史格式 3→4 迁移脚本使用 `tests/fixtures/published-format3/worlds` 中保留的格式 3 世界和 `tests/fixtures/published-format4` 中的真实格式 4 DLL，避免依赖已经删除的完整旧包。试玩包、源码、开发工具链、测试证据各有用途，请勿将它们当作重复文件删除。

本项目仅配置 Windows x64 导出，保留对应模板；已解压的工具下载包和其他平台模板已清理。`bootstrap.ps1 -Templates` 在所需 Windows 模板完整时复用现有文件。清理明细见 `test-results/project-cleanup.json` 与 `test-results/project-cleanup-2026-10-12.json`。

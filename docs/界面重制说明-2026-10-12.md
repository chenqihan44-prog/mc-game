# 方野：余烬灯塔——灯塔金色界面

本版依据用户提供的六张 UI 图重制整个界面：夕阳营地与灯塔背景、夜色探索日志、暖白文字、深色半透明面板、金色圆角边框与高亮。图中未展示的暂停、新建世界、背包、工作台、地图、制作、图鉴、设施、世界规则、删除恢复和联机界面也采用同一控件主题。

## 运行

完整解压 `builds/EmberLighthouse-lantern-ui试玩包.zip`，双击 `EmberLighthouse.exe`。同目录的 PCK 和运行时目录必须保留，不需要另装 Godot 或 .NET SDK。旧跳跃修复包和上一版联机包保留。

保留原有用户存档与键位；世界格式仍为 8。双方联机时需使用本次同一份 UI 包，不与旧版 DLL/PCK 混用。开房与 ZeroTier 步骤见 [联机试玩说明](联机试玩说明-2026-10-12.md)，主菜单“加入联机世界”与暂停菜单“开放联机”均保留。

## 界面与操作

- 主菜单保留新建、读取与备份、加入联机、设置、帮助、制作人员和退出；真实控件分别响应鼠标与键盘焦点。
- 世界管理显示种子地形缩略图、模式、种子、天数、编号、保存时间及位置。缩略图为种子自然地形预览，悬浮说明其含义；读取、备份、软删除、恢复和永久删除行为保留。
- 设置分为声音与视角、图像显示和按键绑定，提供金色滑块、下拉选项、开关及可滚动键位列表；保存返回保持可见。按键捕获时 Esc 取消绑定，普通设置页 Esc 保存并返回上级。
- 主要菜单可用 Esc 返回。E 再次关闭背包／工作台，C 再次关闭随身制作；M、J 开关地图与探索日志。正在连接时 Esc 取消连接，返回地址输入界面。
- 背包和工作台保留实际角色预览、装备与制作槽、左键／右键／Shift／拖拽。小窗口时槽位、图标和点击区域一起缩放，为底部按钮预留空间。
- 地图保留缩放、平移、定位、全图和位置标记；日志保留节点选择、缩放、追踪和准确位置开关。追踪按钮固定在详情滚动区外，待解锁目标维持禁用。
- 暂停菜单采用两列操作区。菜单打开时隐藏游戏小地图及快捷栏，避免与界面标题和底部操作重叠；联机世界模拟仍继续，单人暂停行为保留。

## 验证与资源

以原生 Godot 渲染检查 1280×720、1920×1080 和字体比例 1.0／1.4，逐页截图并检查实际控件位置、焦点和关键返回按钮。测试包含原生输入事件、键位重绑及取消、滑块和帧率回调、地图与任务追踪、暂停保存与备份，以及隔离测试世界的删除恢复闭环；测试不会使用或删除玩家已有存档。

最终测试记录位于 `test-results/ui-style.verification.json` 和其中标明的独立运行目录。导出后的四进程 ENet 检查继续覆盖人物互见、独立物品、远端背包点击拖拽、磁盘保存和重连，并验证客户端收到灯塔背景、金边及暖色槽位。最终压缩包摘要及逐文件 SHA256 见 `builds/EmberLighthouse-lantern-ui-SHA256.json`；包核对记录见 `test-results/ui-style-package.verification.json`。

夕阳与夜景背景由内置 `image_gen` 按用户参考图生成，无文字与交互元素；最终资源保存在 `assets/ui/lighthouse-sunset.png`、`lighthouse-night.png`，完整提示词在 [generation-prompts.md](../assets/ui/generation-prompts.md)。所有按钮、图标、滑块、开关、物品格和任务节点仍由游戏实际绘制并处理输入。许可说明已同步更新。

本轮解决了原生检查发现的创建页面返回裁切、背包关闭裁切，以及游戏 HUD 透过菜单重叠的问题；先前失败日志保留。自动检查仅把完整精确匹配的沙箱 Windows 证书库读取诊断单独分类，其他引擎错误、资源泄漏和非零退出仍视为失败。未把本机多人检查表述为异地真人或长期稳定性测试。

联机样式的首次附加检查错误地依赖未通过协议保留的节点名称；已改为直接校验加载的背景资源路径，失败运行目录保留。退出流程复查同时发现并修正断线后的失效 ENet Host 访问，以及房主关闭房间后仍残留联机目标选择器的问题；关闭房间后恢复单人的敌人与投射物处理，朋友返回主菜单，房主继续原世界。

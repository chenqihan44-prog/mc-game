# 方野：余烬灯塔 · 开发试玩版

当前扩充版的物品、七材质护甲、养殖/驯服/骑乘及炼金说明见《物品生物与护甲更新-2026-10-12.md》。新世界使用生成器 7；旧世界地形保留，存档迁移到格式 7，首次保存前自动保留原档备份。暂停菜单新增「物品与生物图鉴」。

本次光照、贴墙火把、奖励箱开关和落地拾取规则见《光照与掉落更新-2026-10-12.md》。深洞需要放置火把或提灯才能看清，手持不会照亮周围。挖掘、收获和怪物掉落不会直接进入背包，需要走近拾取。

本版修复跳跃后向脚下放方块造成的空中停顿；碰撞即时提交，光照在后台更新。存档格式不变，旧世界可继续读取。详见《跳跃放块修复-2026-10-12.md》。

双击同目录 `EmberLighthouse.exe`。请保留 `.pck` 与 `data_EmberLighthouse_windows_x86_64` 文件夹；本包自带 .NET 运行时，不需要安装编辑器。

这是一份正在实现 S0–S7 的开发样板，尚未完成正式试玩、性能与产品验收。

本版加入三塔归火主线、五处遗址、四种新怪物模型与约11格高的巨像。保留可操作的3×3工作台、图形配方册、立体角色预览和第一人称持物动画；目录现有206个条目。

Q打开工作台后，点击左侧配方图标会把真实材料填入九宫格；材料不足时显示半透明的摆放提示。也可用左键、右键或拖拽手动摆放，配方支持左右镜像和格内平移。点击右侧结果格取出成品，Shift点击批量合成。关闭工作台或保存时，格内材料会归还背包；背包满时保存在脚下的独立落地物品中。自动填入保留其余背包格子的位置。新主线的灯塔符印需要在校准台制作；旧世界保留工作台旧配方。其余制作以配方图标和数量为准。

挖掘时目标表面逐步出现裂纹，准星下方显示进度条，并有受击碎屑和完成破坏的散落动画。手中物品随快捷栏切换，走动、转动视角、挖掘、攻击和放置时有相应动作。背包角色采用有面部、衣服纹理和装备外观的3D模型，头部会轻微跟随鼠标。

## 创建与操作

主菜单可新建世界，输入整数种子并预览开局区域。新世界加入六种地貌、三种树木和八种草花植物；旧世界地形保留。世界管理可普通删除并恢复，也可永久删除世界、已删除副本和指定备份。探索版地形版本 4 的旧世界可点击「更新自然地表」降低植被密度、分散出生物资，保留建筑和进度。新世界直接使用地形版本 7。按 J 打开可拖动、缩放和点击节点的任务导图。生存模式需要采集与制作；休闲模式死亡保留物品；创造模式可从背包中的目录获取材料并飞行。

WASD 移动，Space 跳跃，Shift 蹲伏防坠，Ctrl 疾跑。左键挖掘/攻击，右键放置/进食/播种。数字 1–9 或滚轮选快捷栏。E 物品栏，C 配方，Q 使用设施；G 丢出物品，靠近自动拾取，R 旋转构件，M 地图，Esc 暂停。F 交换主副手，创造模式 V 开关飞行。F3 显示调试信息。设置可重新绑定按键；旧设置若将飞行设为 F，会保留该绑定并默认用 H 换手。

快捷栏与状态显示采用 MC Java 版常见布局。物品栏为 27 格储物区加 9 格快捷栏，左侧有头盔、胸甲、护腿、靴子四格和角色预览，旁边有副手格，右上有可用的 2×2 合成格。左键取放整组，右键取半/放一个，Shift 快捷移动，支持拖拽。装备槽只接受对应部位；在普通背包中 Shift 点击盔甲或盾牌可移入空装备槽，手持盔甲右键也可穿入空槽。关闭界面会归还鼠标和合成格的物品，背包满时溢出放在脚下的独立落地物品中。

工作台可以制作铁头盔、铁胸甲、铁护腿、铁靴子，分别耗铁锭5/8/7/4，共24个。耐久上限分别165/240/225/195，受攻击磨损后显示耐久条，耗尽会损坏；整理和换手保留磨损。穿齐提供15点护甲，在本游戏规则中减少60%的攻击伤害，跌落、溺水和饥饿仍直接扣生命。该数值是本游戏的简化规则。快捷栏左侧显示副手，生命上方显示护甲。主手没有可用的右键动作时，会尝试副手食物、种子或方块。

左上角的小地图朝北，白色箭头显示玩家位置与朝向，金色/青色标记是未激活/已激活的灯塔，棕色点是死亡掉落位置或旧版拾取袋，白色点是 M 地图添加的标记。附近建筑修改会更新到地图；下方显示 X/Z 与天气。出生地可采集原木显示为贴地的短木段，树干和建造用原木仍为完整方块。

按 M 打开大地图，再按 M 返回游戏。左键/中键拖动，滚轮围绕鼠标位置放大缩小，也可点击＋/－；“定位玩家”回到角色位置，“全图”查看整个地图范围，“标记当前位置”留下蓝色标记。地图只显示已探索区域，未探索地形与其中的灯塔隐藏；实际行走揭开附近区域，已探索内容随存档保留，仅拖动和缩放不揭开地图。地图按当前地表、树木和建筑绘制，放置或拆除后自动刷新；放大显示方块细节，缩小时为概览。悬浮标记查看坐标与灯塔状态。查看地图时暂停生存计时。旧存档缺少过去的行走路线，从当前所在位置开始累计探索；新建世界采用自然过渡的出生区地形，旧世界保持原地形以保留建筑。

即使在原散落木段的位置重新放置原木，也会保留建造方块的外形与碰撞。门需要两格净空，打开后可穿过门口，旋转后的门板仍有碰撞；拆除任一半只返还一件门。越界或空间受阻的放置和播种不会扣除材料。

生物可以跳上一格台阶。关闭门能阻挡追逐，普通生物可以经过开启的门；守护者体型更大，不能按普通生物的门口宽度判断。行进途中改变地形会触发重新寻路。

受伤时画面会出现透明红色薄层，并在约0.3秒内淡出；连续伤害不会叠加成不透明遮罩，闪烁触发间隔至少0.65秒。设置中的「受伤画面闪烁」可以关闭这一效果，文字与声音提示仍保留。暂停、打开界面、死亡或退出世界都会清除闪烁。

世界会在晴天、多云与降水之间变化；普通生态区下雨，寒冷生态区下雪，干燥区仅阴天。云层、光线与雨声随天气变化，进入有顶遮蔽处会隐藏近身雨雪并减弱雨声。暂停与读档会保持天气进度；设置中可关闭雨雪粒子。莓果灌木使用原创像素枝叶与果实的透明交叉贴片。

## 三塔归火主线

新建世界体验新版：废矿场哨长 → 寻路塔 → 旱地熔炉堡 / 雪岭观测所（均需完成，顺序自选）→ 校准塔 → 深层晶穴守护者 → 镇封塔 → 地心遗址 → 熔心巨像。按 J 查看日志，勘测镜右键给出方向与距离，可在日志开启精确位置提示。旧存档保留原路线。

修复三座塔总共需要铜线圈×5、铁锭×12、灯塔符印×1；棱镜和晶核作为永久藏品记录，不占背包，死亡保留。校准台制作余烬合金、武器与符印。工作台/校准台的装备维护可安装耐热衬片，或用修理包补充 40% 最大耐久。

地心遗址需用坚实方块补齐六格电桥，在碑文旁校准反射器，再击败供能室守卫。启动核心后先关闭四个锚点；高台锚点可射箭或登阶梯接近。巨像约 11 格高，重击预警后撤出圆圈，再利用核心暴露窗口输出，生命低于 35% 加快节奏。死亡或撤退只重置本场挑战，灯塔与机关保留；标准死亡背包移到遗址地表入口。

当前难度与 10–14 小时首通是设计目标，尚未通过实际玩家全流程计时确认。详见同目录「三塔归火更新.md」。

## 首次生存

采集出生地原木、碎石和莓果；制作木板、木棍与石镐；接着做工作台、营火、箱子和小屋。Q 打开设施；制作计时在返回游戏后推进，产出在设施容器中。

工作台、营火和熔炉需放置在附近才能使用对应配方。石镐可以挖掘岩石、煤矿和铁矿；在熔炉中用粗铁×2、煤×1，等待8秒得到铁锭×2。Q 打开熔炉后选择「取出设施物品」，把铁锭移回背包，再在工作台制作铁镐。离开或拆掉设施后，它不再提供制作能力；设施忙碌或产物容器已满时，不扣除新材料。制作中或等待产物空间的设施不能拆除；先等待完成并取空产物，再拆除设施。

关闭物品栏时，鼠标持物和合成格物品会归还背包；背包满时剩余物品进入可回收背包，数量与已有耐久保持不变。

创建世界时可开启一个出生奖励宝箱，默认关闭。普通野外箱约六分之一的遗迹区域生成，主线箱保留。标准死亡后背包、盔甲和副手分别落地，磨损保留，靠近身体接触后拾取；拾取后需重新穿戴。地图保留死亡位置，休闲死亡保留装备，多次死亡保留之前的掉落。

自动保存每 60 秒一次，暂停菜单也可保存与备份。主菜单读取已有世界。存档通常位于 `%APPDATA%/Godot/app_userdata/方野：余烬灯塔/worlds`。保存错误会明确提示，请保留原目录，不要用空世界覆盖异常存档。

启动时若存档根目录、世界目录或设置文件无法读写，会显示「无法访问存档目录」、实际访问路径和原因。确认可读写、磁盘空间充足，并解除文件占用后点击「重试」，成功后进入主菜单读取原有世界；也可点击「退出」。重试不会改用另一处空白存档目录。启动检查会短暂写入独立临时文件，关闭后自动移除。

保存与世界文件操作在后台进行，状态栏会显示保存进度和上次成功时间。返回主菜单或关闭窗口会等待最终保存；失败时会保留当前世界供重试。旧格式存档可以读取，第一次升级保存前会自动备份原格式；来自未来版本的存档会拒绝读取或覆盖。损坏最新保存时恢复最近完整代际，并明确提示。

主菜单「读取与备份世界 → 从备份恢复」可把校验通过的备份恢复为新世界。原世界和备份均保留；损坏或不受支持的备份不会被覆盖或伪装成成功。

本版保存格式为5，增加三塔归火进度、永久关键藏品、机关、巨像战斗阶段与耐热衬片，保留装备耐久、攻击前摇与飞行中的箭。格式1/2/3/4只在内存迁移，首次保存前自动备份原格式。旧世界保留原地形与原路线；新建世界使用新版主线。旧版程序无法读取格式5，请保留旧备份。

## 测试反馈

测试流程见同目录 `试玩流程.md`。`试玩记录.csv` 和 `性能记录.csv` 是空白记录表，需要填写实际结果。请提供匿名玩家编号、种子、硬件、包哈希，以及问题的复现步骤。请特别记录启动失败、崩溃、存档损坏、物品复制、掉入未加载区域和关键路线卡点。

声音可分别设置主音量、音效、环境和音乐。世界暂停时停止环境推进与生物声音，菜单操作仍有反馈。提灯会自动照亮附近；同时最多启用六个近场光源。帮助菜单可跳过或重新显示新手引导。

材质脚步、敲击、破坏及放置声使用四种变化，脚步较轻；拆除不再叠加拾取提示音。创造模式短按左键拆一格，长按每0.25秒继续拆除；一扇双格门作为整体拆除。关闭菜单返回后先松开鼠标，再开始挖掘或放置。

新播种的胡萝卜180秒、小麦270秒、土豆360秒成熟，暂停时停止计时。旧档已有作物保留原270秒周期；背包放不下收获物和种子时保留成熟作物及原有物品。

林地/草原可见动物，地下有爬行者，遗迹附近有哨兵；游魂可在夜间出现。营火周围7格为有限安全区，进入安全区会打断普通敌人尚未完成的攻击，遗址精英和 Boss 不受影响。普通生物离玩家过远后会离开模拟，附近生物会逐步补充；旧世界守护者在第三座灯塔；新世界在深层晶穴，击败后不会因退出重进而复活。

持弓左键射箭，非创造模式每次发射消耗一支箭，射空也会消耗。箭和哨兵的光弹都有飞行时间，遇到阻挡会停止；侧移可以躲开。野猪受攻击后会沿预警箭头冲锋，冲锋开始后不追踪侧移。守护者攻击前会显示橙色圆圈，及时离开圈内可以避开重击。主手持盾，或副手持盾且主手不在使用方块、食物、种子或弓时，按住右键面对来袭方向可以减少伤害；只装备盾牌不会自动格挡。暂停停止攻击计时；保存重进会续接未结束的前摇和投射物。

浅水中脚踩到底部时，Space 可正常跳上一格高的岸边。工作台、营火和熔炉需要实际存在且在附近；拆掉或离开设施后不能继续制作，忙碌或产物容器满时不会扣材料。

世界水平边界为±2048，高空飞行也受水平边界限制，抵达时会显示提示。建筑高度为192格。前方地形仍在加载时，角色会暂时停止移动，等待可安全通过。

当前限制：战斗平衡、完整成长路线及长期探索时长尚未验收；新增声音、材质、装备画面和照明仍需试听与体验反馈。静态水不支持搬运或动态流动。多人、模组和手柄不在首版范围。旧构建曾出现一次耐久句柄错误，最新构建的长期复验结果以测试报告为准。

本版修正了启动日志路径打开失败后触发原生内存错误的问题；存档目录本身仍必须可写，目录失败时的界面恢复流程尚需完善。此修正不代表鼠标短暂闪黑或其他崩溃已全部解决。

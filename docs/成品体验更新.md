# 2026-10-11 成品体验开发版

按本次试玩反馈，先推进成品开发，集中Bug回归放在内容完成后。本版交付以下体验：

- 工作台改为图形配方册、真实3×3材料格与结果格。支持搜索、可合成筛选、分页、自动填入、手工取放/拖拽、左右镜像与平移、Shift批量合成。材料不足时用半透明图标显示摆放提示。
- 94种物品使用原创32像素图标：工具有对应轮廓与材质，食物、种子、矿物、材料、盔甲和特殊构件有不同图案。快捷栏、背包、配方与创造目录统一使用图标。
- 挖掘加入十阶段表面裂纹、准星下进度条、受击碎屑与破坏散落。裂纹按门、楼梯、半砖、栏杆和地面木段的形状显示。
- 背包角色改为有六面像素皮肤、衣服、头部转动与穿戴外观的3D预览；调整内部格子位置并去掉浅色面板文字的黑色阴影，避免原截图中的标签叠压。
- 第一人称显示手臂与实际手中物品。方块使用有面纹理的模型，工具和材料使用带厚度的像素模型；有换物下落/抬起、行走摆动、视角轻微跟随、挥动、挖掘和放置动作，副手也可显示。

关闭界面与保存时归还工作台材料，满背包溢出留在可回收背包；装备已有磨损保留。自动填入不整理其他背包格子。保留94物品、64配方、48方块及既有材料成本；世界存档格式仍为4，原来的2×2随身合成格继续可用。

持物视图在暂停、打开界面、退出世界与主菜单中停止渲染。

验证范围：核心规则、独立Windows EXE无窗口启动和本轮成品交互检查。无窗口检查能够核对真实按钮、物品事务、模型节点、动画状态与保存读回，不能证明实际画面、手感、性能或真人关卡已通过。本轮不重跑上一版的完整导航、战斗、建筑与30分钟耐久矩阵；S0–S7尚未全部验收。

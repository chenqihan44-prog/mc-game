# 方野：余烬灯塔——四人联机试玩

本版采用玩家开房与虚拟局域网，总人数最多 4 人，包含房主。房主电脑运行世界、怪物和保存；朋友各自拥有角色、背包、装备及生存状态。房主退出后房间关闭。

## 下载与启动

将 `EmberLighthouse-multiplayer试玩包.zip` 发给朋友，每个人完整解压后双击 `EmberLighthouse.exe`。EXE、PCK 和 `data_EmberLighthouse_windows_x86_64` 必须放在一起，不需要安装 Godot 或 .NET SDK。所有人使用同一份包。

## 异地组网

1. 房主与朋友安装 [ZeroTier One](https://www.zerotier.com/download/)。
2. 房主在 [ZeroTier Central](https://central.zerotier.com/) 创建私有网络，将 Network ID 发给朋友。
3. 所有人加入该网络，房主核对设备地址后授权各设备。连接正常后，控制台会显示每台电脑的 Managed IP。
4. 找到房主的虚拟 IPv4 地址，朋友用 `ping 房主虚拟IP -n 30` 检查连通性。若 Ping 不通，先检查授权、地址冲突与 ICMP 防火墙规则。

Network ID 用于加入 ZeroTier 网络，Managed IP 用于加入游戏；两者不要混用。ZeroTier 组网教程见 [官方说明](https://docs.zerotier.com/start/)。本项目没有安装组网工具或修改你电脑的防火墙。

## 房主开房

1. 新建或读取自己的世界。
2. 按 Esc，选择“开放联机”。
3. 填写昵称，选择外观，点击“开始开放联机”。游戏会先保存和备份世界。
4. 房间页面会显示本机 IPv4 地址；复制 ZeroTier 网卡对应的地址加端口，例如 `10.147.17.2:24567`，发给朋友。
5. 返回游戏。需要结束房间时，在“联机房间”里选择“关闭联机，继续单人”，或正常保存退出。

游戏端口为 **UDP 24567**。房主防火墙需要允许游戏在 ZeroTier 网卡上接收此端口，规则覆盖网卡实际使用的网络配置文件，并尽量限制到该虚拟网段。无需关闭防火墙或设置路由器公网端口映射。

## 朋友加入

1. 在主菜单点击“加入联机世界”。
2. 填写昵称及房主地址，例如 `10.147.17.2:24567`。
3. 选择“森野游侠”“铜炉工匠”或“霜境旅人”。也保留原版冒险者外观。
4. 点击“加入世界”，等世界同步及出生区域加载完成。

其他玩家能看到你的昵称、选定角色、装备、头部朝向、行走与蹲下。外观属于装饰，不提供不同属性。新访客拥有新背包；再次加入同一世界恢复原角色。

## 合作规则

- 背包、装备、生命、饥饿、经验、复活点与探索记录按玩家保存；建造、箱子、作物、怪物、天气和主线共享。
- 挖掘、放置、拾取、合成和容器物品移动由房主处理。背包支持左键、右键、Shift 与拖拽。
- 箱子及计时设施被一人操作时，其他人需等其关闭。离开或断线会归还临时制作物品并释放占用。
- 联机时打开背包、地图、暂停菜单或切换窗口，世界仍继续运行；单人模式保留暂停。
- 联机睡觉需要全部在线玩家使用床；普通死亡只处理本人的物品。死亡掉落按所属角色回收。
- 默认合作，不支持玩家互伤。重要进度和正常退出保存；自动保存沿用 60 秒。

## 重连与存档

世界在房主电脑保存。玩家身份与重连凭据位于游戏用户数据目录的 `multiplayer-identity.json`，正常目录为 `%APPDATA%/Godot/app_userdata/方野：余烬灯塔/`。

更新试玩包时可以解压到新目录，保持用户数据中的身份文件；不要将自己的身份文件分享给其他朋友。删除身份文件后会被当作新角色。房主强制关闭或断电时，以最近完整存档恢复；尚未保存的进度可能丢失。

存档格式更新为 8，旧版本存档可迁移并保留旧地形生成版本。开启联机前会备份；格式 8 存档需要使用本版或之后兼容的版本读取。

## 排障

- 地址错误：游戏应填写虚拟 IP 和 `:24567`，不是 Network ID、房主家里的普通 Wi-Fi 地址或 `127.0.0.1`。
- Ping 通但游戏连不上：确认房主已开放联机、UDP 端口未被防火墙拦截，以及两边使用同一个包。
- 延迟高：查看 `zerotier-cli peers` 中目标设备是否走中继；更换有线网络并停止大文件上传作对照。参考 [ZeroTier 中继说明](https://docs.zerotier.com/faq/relaying/)。
- 提示版本不一致：重新完整解压同一份联机包，不混用旧 EXE、PCK 或 DLL。
- 重连凭据不匹配：检查是否替换过身份文件或同一个身份正在另一台电脑上线。

当前版本是合作试玩版。自动验证覆盖本机四个独立进程的真实 ENet 连接、互相可见的角色、物品与建造同步、背包操作、保存和重连；实际异地延迟、不同运营商连接和长期多人战斗需要在你们的网络中试玩确认。验证不会将本机测试表述为已完成异地真人试玩。
